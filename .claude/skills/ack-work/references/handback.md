# ack-work hand-back

- The route, why, and whether a `<jev_route>` block set it.
- The plan file path and the owner's yes; on `feature`, the design path and the `.superpowers/sdd/<plan-basename>/progress.md` ledger.
- Each agent's hand-back in one line, with its model and effort.
- Files changed; status codes allocated; the schema delta and the owner's `pnpm db:migrate`.
- The review: each finding and its state (fixed, rejected with reason, parked, open), and each sweep-log row appended.
- The follow-up: the `<jev_followup>` block or direct decision, the owner's docs answer, the docs `writer` changed, and the harness change or the owner's no.
- The `pnpm test` output.
- The proposed commit subject.
- One line per thing noticed outside scope.
